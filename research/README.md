# Research

> **Read this when** you are about to start a study, write a paper or submit one, and want the lab's standards in one place.

These pages cover how research is done and published in the Advanced Telerobotics Research Lab: the standards every project follows, how to write a paper for ACM and IEEE venues in LaTeX, and the checklist to run before you press submit. Kent State University's policies and the publisher's rules always win; these pages point you to them.

| Page | What it covers | Read it when |
| --- | --- | --- |
| [Research standards](standards.md) | Research integrity, human-subjects research (IRB and CITI), authorship, citations, data management, reproducibility, preprints and news timing, generative AI, the affiliation line, funding acknowledgments | Before you start a project or a study |
| [Writing papers](writing-papers.md) | LaTeX basics, IEEEtran vs acmart, a table of the lab's usual venues, Overleaf, figures and video, camera-ready and copyright forms | When you start a draft |
| [Publishing checklist](publishing-checklist.md) | Every check to run before you submit a paper or post a preprint | The week before a deadline |
| [LaTeX templates](../templates/latex/README.md) | Compilable IEEE and ACM skeletons with the lab's affiliation block | When you start a draft |

> [!IMPORTANT]
> Any study that involves people (surveys, interviews, user studies, recordings of people interacting with a robot) needs Kent State IRB review before you recruit anyone. Start with [human-subjects research](standards.md#human-subjects-research).
